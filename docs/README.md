# Documentação e Manuais

Esta pasta é reservada para armazenar informações, manuais, guias e qualquer outra documentação pertinente ao projeto **CyberTech RH - HR-HUB PLUS**.

## Organização Sugerida

Você pode criar subpastas aqui para separar diferentes tipos de documentos, por exemplo:

- `/manuais`: Para manuais de usuário ou de instalação.
- `/tecnico`: Para especificações técnicas, diagramas de arquitetura, etc.
- `/recursos`: Para imagens, ícones ou outros materiais estáticos não incluídos diretamente no código fonte.
